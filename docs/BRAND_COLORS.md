# Kiwmee — โทนสี

ชุดสีของแบรนด์ **Kiwmee** (ครอบครัวเดียวกับ CheckMee, DealMee) · โทน **ม่วง Grape + มินต์** (แบบ B "Popin" จากบอร์ดแบรนด์)
อารมณ์: เป็นมิตร สดใส ใช้ได้กับทุกธุรกิจที่รับจอง · ไม่ใช้เขียวเป็นสีหลัก เพราะการ์ดจะอยู่ใน LINE ที่เป็นสีเขียวอยู่แล้ว

---

## 1. สีหลัก

| ชื่อ | HEX | ใช้กับ |
|---|---|---|
| **Grape** | `#6A4CFF` | สีหลักของแบรนด์ · ปุ่มหลัก · ลิงก์ · ตัว "mee" ในโลโก้ · แถบหัวการ์ด LINE |
| **Mint** | `#3DDC97` | สีเน้นคู่ · จุดในโลโก้ · ไฮไลต์ · ป้าย "ว่าง" / "สำเร็จ" (ตัวอักษรบนมินต์ใช้ Ink เท่านั้น) |
| **Ink** | `#1B1640` | ตัวอักษรหลัก · หัวข้อ · พื้นเข้ม · ช่องที่ถูกเลือก |

## 2. สีพื้นและเส้น

| ชื่อ | HEX | ใช้กับ |
|---|---|---|
| **Mist** | `#F7F5FF` | พื้นหลังหน้า |
| **White** | `#FFFFFF` | การ์ด · กล่องฟอร์ม · ช่องกรอก |
| **Lilac** | `#ECE8FF` | พื้นของสิ่งที่เลือกแล้ว (ชิป, แถวที่เลือก) · ป้ายข้อมูล |
| **Line** | `#DCD6F5` | เส้นขอบช่องกรอก · เส้นแบ่ง (ตกแต่งเท่านั้น ไม่ใช้เป็นตัวอักษร) |
| **Line soft** | `#E8E4F8` | เส้นแบ่งแถวในการ์ด |

## 3. สีตัวอักษรรอง และสีสำหรับตัวอักษรขนาดเล็ก

| ชื่อ | HEX | ใช้กับ |
|---|---|---|
| **Muted** | `#5F5A7A` | ข้อความรอง · คำอธิบาย · label |
| **Grape deep** | `#4F33E0` | ลิงก์/ตัวอักษรม่วงบนพื้น Lilac · hover ของปุ่มหลัก |
| **Grape night** | `#3A22B8` | ปุ่มหลักตอนกด (active) |
| **Mint deep** | `#0B7A50` | ตัวอักษรสีเขียวบนพื้นขาว เช่น "ว่าง", "บันทึกแล้ว" (Mint ปกติอ่านไม่ออกบนขาว) |
| **Mint tint** | `#E3FAF0` | พื้นป้ายสถานะ "ยืนยันแล้ว" / "ว่าง" |
| **Grape light** | `#9B87FF` | สัญลักษณ์โลโก้บนพื้นเข้ม |

## 4. สีสถานะ

| สถานะ | ตัวอักษร | พื้น | ตัวอย่าง |
|---|---|---|---|
| สำเร็จ / ว่าง | `#0B7A50` | `#E3FAF0` | จองสำเร็จ · ยืนยันแล้ว |
| ข้อมูล / เลือกแล้ว | `#4F33E0` | `#ECE8FF` | เลือกแล้ว · มาถึงแล้ว |
| เตือน | `#B54708` | `#FFF4E5` | ใกล้เต็ม · รอชำระเงิน |
| ผิดพลาด / ยกเลิก | `#B42318` | `#FEF3F2` | เพิ่งถูกจอง · ยกเลิกแล้ว |
| ปิด / ไม่ว่าง | `#5F5A7A` | `#F7F5FF` | ร้านปิด · เต็ม (สีเทา + บอกเหตุผล) |

## 5. คู่สีที่ใช้ได้ (ความต่างของสี ตามเกณฑ์ WCAG)

ตัวอักษรปกติต้อง ≥ 4.5:1 · ตัวใหญ่ (24px ขึ้นไป หรือ 19px ตัวหนา) ≥ 3:1

| ตัวอักษร | บนพื้น | ค่า | ใช้ได้ |
|---|---|---|---|
| Ink `#1B1640` | White / Mist | 17.0 / 15.8 | ทุกขนาด |
| Muted `#5F5A7A` | White / Mist | 6.5 / 6.0 | ทุกขนาด |
| White | Grape `#6A4CFF` | 5.1 | ทุกขนาด (ปุ่มหลัก) |
| Grape `#6A4CFF` | White / Mist | 5.1 / 4.8 | ทุกขนาด (ลิงก์) |
| Grape deep `#4F33E0` | Lilac `#ECE8FF` | 6.1 | ทุกขนาด |
| Ink `#1B1640` | Mint `#3DDC97` | 9.6 | ทุกขนาด (ปุ่ม/ป้ายมินต์) |
| Mint deep `#0B7A50` | White / Mint tint | 5.4 / 4.9 | ทุกขนาด |
| White | Ink `#1B1640` | 17.0 | ทุกขนาด (พื้นเข้ม) |
| Grape light `#9B87FF` | Ink `#1B1640` | 5.9 | ทุกขนาด |

**ห้ามใช้:**
- ตัวอักษร Mint `#3DDC97` บนพื้นขาว (1.8) → ใช้ Mint deep `#0B7A50` แทน
- ตัวอักษร White บนพื้น Mint → ใช้ Ink แทน
- Grape `#6A4CFF` เป็นตัวอักษรเล็กบน Lilac (4.3) → ใช้ Grape deep `#4F33E0`
- Mint วางชิดกับ Grape เป็นคู่ตัวอักษร/พื้น (2.9) · ใช้คู่กันได้เฉพาะในโลโก้และกราฟิก
- Line `#DCD6F5` เป็นตัวอักษร

## 6. โลโก้

| พื้น | สัญลักษณ์ | "kiw" | "mee" |
|---|---|---|---|
| ขาว / Mist | Grape + จุด Mint | Ink `#1B1640` | Grape `#6A4CFF` |
| Ink (เข้ม) | Grape light `#9B87FF` + Mint | White | Mint `#3DDC97` |
| Grape (ไอคอนแอป, รูปโปรไฟล์ LINE) | White + Mint | — | — |

ฟอนต์โลโก้: **Mitr** น้ำหนัก 600 ตัวพิมพ์เล็กทั้งหมด

| `kiwmee-logo-white.svg` | โลโก้แนวนอน ขาวล้วน (จุดยังเป็นมินต์) บนพื้น Grape |

## 8. CSS tokens

```css
:root {
  /* brand */
  --grape: #6A4CFF;
  --grape-deep: #4F33E0;
  --grape-night: #3A22B8;
  --grape-light: #9B87FF;
  --mint: #3DDC97;
  --mint-deep: #0B7A50;
  --mint-tint: #E3FAF0;
  --ink: #1B1640;

  /* surfaces */
  --bg: #F7F5FF;        /* Mist */
  --surface: #FFFFFF;
  --selected: #ECE8FF;  /* Lilac */
  --line: #DCD6F5;
  --line-soft: #E8E4F8;
  --muted: #5F5A7A;

  /* status */
  --ok: #0B7A50;     --ok-bg: #E3FAF0;
  --info: #4F33E0;   --info-bg: #ECE8FF;
  --warn: #B54708;   --warn-bg: #FFF4E5;
  --danger: #B42318; --danger-bg: #FEF3F2;

  /* type */
  --font-display: "Mitr", sans-serif;
  --font-body: "Anuphan", sans-serif;

  /* shadow */
  --shadow: 0 8px 24px rgba(27, 22, 64, 0.08);
}
```

ปุ่มหลัก: พื้น `--grape` ตัวอักษรขาว · hover `--grape-deep` · กด `--grape-night`
ปุ่มรอง: ขอบ `--grape` ตัวอักษร `--grape` พื้นโปร่ง
ช่องเวลาที่เลือก: พื้น `--ink` ตัวอักษรขาว · ช่องที่ไม่ว่าง: พื้น `--bg` ตัวอักษร `--muted` + เหตุผล
