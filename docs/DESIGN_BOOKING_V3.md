## 5. Must-fix UX (ตรวจซ้ำทีละหน้าจอหลัง integrate)

1. หัวเรื่องต้องเป็นไทยล้วน (ไม่มี Service Selection / Booking Confirmation)
2. ข้อความขั้นตอนรูปแบบเดียว "ขั้นตอนที่ N จาก 4"
3. ไม่ใช้ `user-scalable=no` / `maximum-scale=1`
4. ตัวอักษร ≥12px · ปุ่ม/ชิป ≥44px
5. `…` แทน `...` · ชื่อยาว `line-clamp-2`
6. วันปิดต้องมีคำ ("ปิด") ไม่ใช้สีอย่างเดียว
7. คำผิด: คิวแนะนำ · ช่างไหนก็ได้ · ดิจิทัล · "เวลาที่เหลือไม่พอ"
8. State ครบ: ไม่มีคิวว่าง / ร้านปิด / **คิวถูกจองตัดหน้า** / loading
9. ลิงก์ `/privacy` ในหน้าข้อมูลผู้จอง
10. ไม่มีข้อความ VAT / SMS / LINE ID ซ้ำซ้อน (ตรวจแล้วไม่พบในโค้ด — ยืนยันอีกครั้งตอนทำ UX)
