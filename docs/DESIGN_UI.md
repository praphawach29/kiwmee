# ออกแบบหน้าจอ 3 role (ลูกค้า · ร้าน · ผู้ดูแล)

เอกสารนี้กำหนดโครงหน้า องค์ประกอบ และกติกาการแสดงผลให้เหมือนกันทุกหน้าจอ — ใช้คู่กับ `app/ui/ui.css`
(พื้นฐานที่เริ่มใช้แล้วกับ **กระเป๋าเงิน** และ **รายงานรายได้/สลิปของ /super**)

## 1. หลักการ

1. **หนึ่งหน้า = หนึ่งงานหลัก** — ถ้างานหนึ่งต้องใช้สองหน้าจอ ให้แยกเป็นขั้น (เช่น หน้าจอง 3 ขั้น)
2. **ปุ่มหลักหนึ่งปุ่มต่อหน้า** ปุ่มรองใช้สีขาวขอบเทา ไม่แย่งสายตา
3. **แตะง่ายบนมือถือ** — ทุกปุ่มสูง ≥44px, ตัวอักษรในช่องกรอก ≥16px (กัน iPhone ซูม), ระยะห่างปุ่ม ≥8px
4. **ตารางต้องอ่านได้บนมือถือ** — ยุบเป็นการ์ดด้วย `.ui-table-stack` + `data-label` (ไม่ต้องเลื่อนแนวนอน)
5. **สถานะใช้สี+คำ ไม่ใช้สีอย่างเดียว** — เขียว = ปกติ, ส้ม = ใกล้ถึงขีด, แดง = หยุด/ผิดพลาด, ม่วง = แบรนด์/ลิงก์
6. **ภาษาคน ไม่ใช่รหัส** — แสดง "ยอดโอนน้อยกว่าที่ขอ" ไม่ใช่ `AMOUNT_LOW` (แมปไว้แล้วในโค้ด)
7. **ทุกหน้าต้องมีทางออก** — ปุ่มย้อนกลับ/ปิด หรือลิงก์กลับหน้าหลักของ role นั้น

## 2. โครงหน้า (ใช้ร่วมทุก role)

```
┌──────────────────────────────────────────────┐
│ header: ชื่อหน้า + คำอธิบายสั้น + ปุ่มหลัก    │  .ui-head
├──────────────────────────────────────────────┤
│ ตัวเลขสรุป 3–4 ก้อน (ถ้ามี)                  │  .ui-stats > .ui-stat
│ การ์ดเนื้อหา 1–3 ใบ                          │  .ui-card
│ ตาราง/รายการ (ยุบเป็นการ์ดบนมือถือ)          │  .ui-table.ui-table-stack
└──────────────────────────────────────────────┘
```
- กว้างสุด 1100px, ขอบข้าง 16px (มือถือ 12px), เว้นล่าง 80px เผื่อแถบนำทางมือถือ
- ฟอนต์: หัวเรื่อง `--font-display` (Mitr) · เนื้อหา `--font-body` (Anuphan)
- สี: ม่วง `--grape #6A4CFF` (หลัก) · มินต์ `--mint` (สำเร็จ) · ส้ม `--warn` · แดง `--danger`

## 3. โครงข้อมูลแต่ละ role

### 3.1 ลูกค้า (มือถือก่อน)
| หน้า | งานหลัก | องค์ประกอบ |
|---|---|---|
| `/b/<slug>` | จองคิว 3 ขั้น | หัวร้าน + แถบวัน + เวลา + การ์ดบริการ → ข้อมูลผู้จอง → ยืนยัน (แถบล่างติดจอ "ราคารวม + ปุ่ม") |
| หน้าสำเร็จ | เก็บลิงก์/ปฏิทิน | ลิงก์จัดการการจอง + เพิ่มลงปฏิทิน + ใช้คะแนน |
| `/b/<slug>/me` | ดูนัด/แต้ม | นัดถัดไป (การ์ดใหญ่) → นัดอื่น → ประวัติ · บัตรสมาชิกปัดซ้าย-ขวา |
| `/manage/<token>` | เลื่อน/ยกเลิก | สรุปนัด + ปุ่มสองปุ่มเท่านั้น |
| `/privacy`, `/terms` | อ่าน | หน้าข้อความยาว อ่านง่าย (`.legal-shell`) |

### 3.2 ร้านค้า
| หน้า | งานหลัก | องค์ประกอบ |
|---|---|---|
| `/dashboard` | เลือกร้าน/แบรนด์ | การ์ดแบรนด์ + สาขา + โควตาข้อความ + ลิงก์กระเป๋าเงิน |
| `/dashboard/<slug>` | งานวันนี้ | ภาพรวม (คิวถัดไป/ยอดวันนี้) · การจอง · บิล · เพิ่มเติม (บริการ/ช่าง/เวลา/สมาชิก/สลิป) |
| `/dashboard/wallet` | เติมเงิน/ซื้อแพ็ก | ยอดคงเหลือ → โควตา → เติมเงิน (สลิป) → แพ็กเกจ → รายการ |
| แถบนำทางมือถือ | 4 ปุ่ม: ภาพรวม · การจอง · บิล · เพิ่มเติม | ไม่เกิน 4 รายการ |

### 3.3 ผู้ดูแลแพลตฟอร์ม (`/super`)
| หน้า | งานหลัก |
|---|---|
| แดชบอร์ด | ตัวเลขรวม + สถานะการตั้งค่า (ใช้ `/api/health`) |
| แบรนด์และแพ็กเกจ | ดู/ตั้งแพ็กเกจแบรนด์ |
| ร้านและสาขา | ค้นร้าน เปิดร้านของลูกค้า |
| การเงิน → สลิปรอเติมเงิน | อนุมัติ/ปฏิเสธสลิป (ใช้ `.ui-table-stack`) |
| การเงิน → รายงานรายได้ | MRR · เงินเติม · ยอดใช้ · ยอดคงเหลือ |
| การตั้งค่า | LINE · บัญชีรับเงิน · กุญแจเข้ารหัส |

## 4. องค์ประกอบที่ใช้ซ้ำ (ใน `app/ui/ui.css`)

| คลาส | ใช้ทำอะไร |
|---|---|
| `.ui-page` | กรอบหน้า (กว้างสุด/ระยะขอบ/ช่องไฟ) |
| `.ui-head` `.ui-title` `.ui-sub` | หัวหน้า + คำอธิบาย |
| `.ui-card` | กล่องเนื้อหา (พื้นขาว ขอบบาง มุมโค้ง 14px) |
| `.ui-stats` `.ui-stat` | แถวตัวเลขสรุป (ยุบเป็น 1–2 คอลัมน์บนมือถือ) |
| `.ui-table` `.ui-table-stack` | ตารางปกติ / ตารางที่ยุบเป็นการ์ดเมื่อจอ <720px (ต้องใส่ `data-label`) |
| `.ui-form` `.ui-field` | ฟอร์ม (input สูง 44px ตัวอักษร 16px) |
| `.ui-btn` `.ui-btn-primary` `.ui-btn-secondary` | ปุ่มหลัก/รอง (เต็มความกว้างบนมือถือ) |
| `.ui-pill-ok/.warn/.danger` | ป้ายสถานะ |
| `.ui-banner-ok/.warn/.danger` | ข้อความผลลัพธ์หลังทำรายการ |
| `.ui-bar` | แถบโควตา/ความคืบหน้า |
| `.ui-empty` | สถานะว่าง ("ยังไม่มีรายการ") |

## 5. จุดตัดหน้าจอ (breakpoints)

| ความกว้าง | การเปลี่ยน |
|---|---|
| < 640px | ปุ่มเต็มความกว้าง · ตารางเป็นการ์ด · ฟอร์มเรียงลง · ระยะขอบ 12px |
| 640–1024px | การ์ดสรุป 2 คอลัมน์ · ตารางยังเป็นตาราง |
| > 1024px | สูงสุด 1100px จัดกลาง · /super มี sidebar |

## 6. สถานะการดำเนินการ

- [x] พื้นฐาน `app/ui/ui.css` (การ์ด/ตารางยุบ/ฟอร์ม/ปุ่ม/ป้าย/แถบโควตา)
- [x] หน้ากระเป๋าเงิน (ร้าน) ใช้พื้นฐานใหม่ + ตารางยุบมือถือ
- [x] `/super` → สลิปรอเติมเงิน, รายงานรายได้ ใช้ตารางยุบมือถือ
- [ ] หน้าจอง/การจองของฉัน (มีโครง mobile-first อยู่แล้ว — รอแบบเพื่อปรับให้เข้าชุด)
- [x] แดชบอร์ดร้าน — ปรับคลาส `ad-*` ให้ได้มาตรฐานเดียวกับ `.ui-*` แล้ว (ปุ่ม/ช่องกรอกสูง 44px, ตัวอักษรในช่องกรอก 16px, ระยะห่างบนมือถือ) โดยไม่ต้องแก้ JSX ขนาดใหญ่
- [ ] หน้า `/super` ที่เหลือ (แบรนด์/ร้าน/ตั้งค่า) — เปลี่ยนตารางเป็น `.ui-table-stack`
