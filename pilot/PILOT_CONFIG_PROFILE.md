## 4. นโยบายการจองและระบบอัตโนมัติ (Booking & Automation Policies)

### 4.1 การยืนยันและการจอง (Confirmation)
- สถานะเริ่มต้น: `confirmed` ทันทีที่การตรวจสอบ Availability และการบันทึกลงฐานข้อมูลใน Transaction เสร็จสมบูรณ์
- ระบบสร้าง Job ส่ง `booking_confirmation` 1 ครั้ง พร้อมจัดตาราง `appointment_reminder` อัตโนมัติ

### 4.2 นโยบายการยกเลิก (Cancellation Window)
- **เงื่อนไข**: ลูกค้าสามารถยกเลิกเองผ่านหน้า Manage Booking (`/manage/[id]`) หรือผ่าน AI ได้ล่วงหน้าอย่างน้อย **24 ชั่วโมง** (`CANCELLATION_WINDOW_HOURS=24`)
- **กรณีเหลือน้อยกว่า 24 ชั่วโมง**: ระบบจะปฏิเสธการยกเลิกอัตโนมัติ และแจ้งให้ลูกค้าติดต่อร้านโดยตรงเพื่อให้ผู้จัดการร้านพิจารณาตามดุลยพินิจ

### 4.3 นโยบายการเลื่อนนัด (Reschedule)
- ลูกค้าสามารถเลือกเวลาว่างใหม่ที่ระบบเสนอได้
- เมื่อการเลื่อนนัดสำเร็จ ระบบจะยกเลิก Job Reminder เดิม และจัดตาราง Reminder ใหม่ตามเวลานัดหมายใหม่ทันที

### 4.4 การจัดการ No-Show
- **Grace Period**: 15 นาที (`NO_SHOW_GRACE_MINUTES=15`)
- หากเลยเวลานัด 15 นาที และสถานะยังเป็น `confirmed` (ไม่ได้ Check-in):
  1. Worker จะเปลี่ยนสถานะเป็น `no_show`
  2. บันทึกประวัติใน `booking_status_history`
  3. จัดตาราง Follow-up Message ส่งหลังเกิด No-show 1 ชั่วโมง (`NO_SHOW_FOLLOWUP_HOURS=1`)

### 4.5 การติดตามผลหลังบริการ (Post-Service Follow-up)
- เมื่อร้านกดเปลี่ยนสถานะเป็น `completed` ที่หน้า Admin
- ระบบจะจัดตารางส่งข้อความขอบคุณและขอคะแนนความพึงพอใจหลังจากนั้น 24 ชั่วโมง (`POST_SERVICE_FOLLOWUP_HOURS=24`)

## 5. มาตรการความปลอดภัยและขอบเขตสิทธิ์ (Security Boundary)

1. **Admin Access**:
   - ไม่มีรหัสผ่าน Plaintext ในระบบ
   - ใช้ Password Hash แบบ `scrypt` (`ADMIN_PASSWORD_HASH`)
   - Session Cookie เป็น HttpOnly, SameSite=Lax (Secure เมื่ออยู่บน HTTPS) มีอายุ 8 ชั่วโมง และสามารถ Revoke ได้ทันทีเมื่อกด Logout
2. **Customer Access Boundary**:
   - การเข้าดูหรือจัดการนัดหมายที่ `/manage/[id]` หรือผ่าน AI ต้องส่งเบอร์โทรศัพท์ที่ตรงกับฐานข้อมูลเสมอ (`x-booking-phone`)
   - ไม่อนุญาตให้ใช้ UUID เพียงอย่างเดียวในการเข้าถึงข้อมูล
3. **Internal Automation Runner**:
   - ป้องกัน endpoint `/api/internal/automation/run` ด้วย Secret Token ขั้นต่ำ 32 ตัวอักษร
4. **AI Receptionist Boundary**:
   - ใช้ Safe Tool Gateway พร้อม Allowlisted Tools 8 รายการ
   - ทุกการสร้าง/เลื่อน/ยกเลิกนัด ต้องผ่านขั้นตอน Server Review และคำยืนยันชัดเจนจากลูกค้าเท่านั้น
   - กรณีขอส่วนลดพิเศษ ร้องเรียน หรือขอข้อยกเว้น จะถูกส่งต่อไปยัง Human Handoff ทันที
